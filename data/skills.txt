# What gets unlocked, and when.
# =============================
#
# This file decides the whole skill tree. The game reads it at startup.
# Change it, restart the game - done. No rebuild needed.
#
# The tree is NOT rolled up front. You always see exactly one step ahead.
# Only when you buy something is the next step rolled - out of everything
# that fits this step AND that you already own.
#
#
# ONE LINE PER POINT
#
#     key           step      price   how often    [needs ...]
#
#   key         what the point unlocks. The list is below.
#   step        from when to when it may show up.
#               "4" means exactly step 4, "3-8" means somewhere in between,
#               "3-" means from step 3 on with no end.
#   price       base price at step 1. Further out everything gets more
#               expensive, see "growth". The base price then only makes the
#               difference WITHIN one step.
#   rise N      optional, only with "often": what the weight is multiplied by
#               per step outwards. 1.2 means the point gets more common the
#               further out you go - that way the "+1" points become the
#               normal case late on, while new commands get rarer.
#
#   how often   "once"    = exists exactly one single time in the whole tree.
#                           A number may follow: how strongly the point is
#                           drawn (without a number: 2).
#               "often N" = may come again and again, N is the weight.
#                           The bigger N, the more often.
#   needs X     the point only shows up once X has been BOUGHT.
#               That is how "+1 condition" only appears once you have "if".
#
# Everything after a # is a comment, empty lines do not matter.
#
# IMPORTANT: step means depth in the tree. A point at step 5 hangs behind
# four others - so you can never have it earlier than your 5th purchase.
#
# With "once" the chance grows towards the end: at the start of its range the
# point is rare, at the end almost certain. And if the range runs out
# completely, it is forced on the last step. So you cannot lose anything.
#
#
# THE KEYS
#
#   while         while and do, plus your first loop
#   for           for, plus one more loop
#   if            if, plus your first condition
#   else          else
#   print         print(...)
#   check         block.isThere(), isLoading(), exists(), isGone()
#   shared        shared["name"] - survives a restart
#   mine          block.mine() - let a program mine instead of clicking
#   care          block.ore(), block.is(Gold) and block.mine(Cool) - valuable
#                 ores want to be cooled or heated, and every ore always the
#                 same way. So you have to ask WHICH ore is standing there:
#                 one if per ore. The wrong treatment is worse than none.
#   sell          item.sell() - turn your bag into money
#   bag           item.has(Stone) - look at what is in your bag
#   variables     your own variables (int, float, ...), plus the first one
#   classes       struct and class, plus the first one
#   functions     your own functions and methods, plus the first one
#
#   wash          item.wash(Stone)   - processing
#   clean         item.clean(Stone)
#   press         item.press(Coal)
#   smelt         item.smelt(Copper)
#   cast          item.cast(Copper)
#   harden        item.harden(Iron)
#   polish        item.polish(Diamond)
#   refine        item.refine(Gold)
#   etch          item.etch(Gold)   - the end of the chain
#   fuse          item.fuse(Gold)
#
#   quests        contracts. Three offers before every round, take one or
#                 none. Comes very late on purpose - see below.
#
#   alloy         item.alloy(Electrum) and item.canAlloy(Electrum)
#                 - melt two ores into one new material
#
#   What works from which state is in data/verarbeitung.json - that is a net,
#   not a fixed chain. The skill tree only says which steps you are allowed to
#   use at all. Which alloys exist is in data/legierungen.json.
#
#   loop+         one more loop allowed
#   condition+    one more condition allowed
#   variable+     one more variable allowed
#   class+        one more class allowed
#   function+     one more function allowed
#   console+      one more console - and that now means one more PROGRAM.
#                 Every console with its own main() runs as its own process
#                 with its own line budget, so two consoles really are twice
#                 the work: one mines while the other sells. That makes this
#                 the strongest point in the whole tree, which is why it is
#                 late, expensive and rare.
#
#   speed         +0.5 lines per second
#   money         +1 money per block
#   regrow        the block regrows 8% faster
#
#
# MORE LANGUAGE
#
#   switch        switch/case/default. A whole switch is ONE line, however
#                 many cases hang under it - an else-if chain costs a line per
#                 rung. It uses up no condition. Until this point existed all
#                 of that was free, and buying "if" was optional for anyone who
#                 knew C++.
#   ternary       a ? b : c - a condition inside a line, costing no line and
#                 no condition of its own.
#   goto          goto and labels. A loop that uses up no loop.
#   recursion     a function may call itself. Also a loop, also without
#                 spending one.
#   container     vector, array, map, set. The container counts as one
#                 variable, what is inside it is free.
#
#
# THE COMPILER
#
#   inline        lines INSIDE your own functions cost only half. Without it a
#                 function is slower than writing the code twice.
#   optimize      lines per second TIMES optimize_mul instead of plus a fixed
#                 amount. The only point in the tree that multiplies - so it
#                 is worth little early and a lot late.
#
#
# QUESTIONS TO THE WORLD
#
#   info          info(ore) - value, rarity, level and above all the treatment
#                 an ore wants, as a pointer. nullptr = not examined yet.
#                 With it ONE program fits every ore, including the ones the
#                 game invents later. Without it the treatment has to be
#                 written out ore by ore, for ever.
#   assay         assay(ore) - examine an unknown ore. Costs money and time,
#                 afterwards info() knows.
#   count         item.count(ore) and item.purity(ore) - the number and the
#                 purity, instead of only yes or no.
#   job           job.busy(), job.idle(), job.progress() - is a furnace free.
#   wait          wait(seconds) and block.loading() - waiting without burning
#                 a line per pass.
#   status        money(), timeLeft(), roundTarget().
#   market        market.price(ore) and market.average(ore) - prices move
#                 during the round. Until this point is bought nothing moves
#                 at all: every ore sits on its base value. A price that
#                 swings while you cannot read it is a dice roll nobody sees.
#   chart         the Market page: a chart of every ore you have held, with
#                 its base value, what it costs right now and how the price
#                 ran. The number was already there - here you watch it move,
#                 and holding a stack back becomes a decision instead of a
#                 guess.
#
#   furnace+      one more job at the same time. Processing and alloying share
#                 the places; at the start there is exactly one, and that was
#                 the hardest ceiling in the game.


# This many steps the tree has. 0 = no end, it keeps growing forever.
steps       0

# The further out, the more expensive: every step costs 1.8 times as much.
# That is why you clear out the nearby points first and then work outwards.
growth      1.8

# This many new points one purchase opens up (smallest and largest number).
children    1 3

# This many points stand open at most at the same time. If that many are
# already open, a purchase only opens exactly one new one.
open        10

# What "optimize" multiplies the speed by. 1.2 = a fifth more, and it stacks.
optimize_mul  1.2

# What assay() costs and how long it takes.
assay_cost     40
assay_seconds  3.0

# How far the market price swings around the base value (0.25 = +/- 25 %)
# and how fast it turns.
market_swing  0.25
market_speed  0.06


# Minimum distance between two "once" points, counted in points.
# This many other points must lie in between. That way you unlock one thing,
# play on for a bit, and only then the next one comes - instead of three in
# a row.
#
# Points with a fixed step (e.g. "mine 1") do not follow this: those sit
# exactly where they should.
# There are half again as many one-off points as there used to be. With the
# old distance of 9 the whole tree would take twice as long to walk - so the
# points move a little closer together.
spacing     6


# ---- the language ------------------------------------------------------
#
# Everything here exists exactly ONCE. When you unlock it you get exactly one
# use with it - more only through the extensions below.
#
# The ranges may overlap - the spacing above makes sure there is still air
# in between.

mine           1            6   once 1
sell           2            6   once 1
while          3            8   once 1
if             4-9         18   once 2
variables      6-11        16   once 1
print          7-13        12   once 1
bag            6-11        16   once 2   needs if
check          8-14        14   once 1
care           12-20       22   once 1   needs check
else           10-16       18   once 1   needs if
for            11-17       20   once 1   needs while
functions      12-18       20   once 1   needs variables
classes        14-24       22   once 1   needs functions
shared         15-24       24   once 1


# ---- processing --------------------------------------------------------
#
# Selling raw brings little. Washing sits on a fixed step on purpose: that
# way it comes early and always - otherwise the bag would not pay off for
# far too long.
#
# The later steps build on each other, but not as a single line: casting
# needs smelting, hardening needs casting, refining needs polishing.
# Everything else may come in any order.

wash           8-16        10   once 2   needs bag
smelt          10-18       20   once 1   needs wash
clean          12-20       18   once 1   needs wash
press          13-21       22   once 1   needs wash
cast           14-22       26   once 1   needs smelt
polish         16-24       28   once 1   needs cast
harden         18-26       32   once 1   needs cast
refine         20-32       40   once 1   needs polish

# The end of the chain. Etching costs purity and a lot of time, fusing costs
# even more - but "fused" is worth more than twice what "refined" is. Late in
# the game a stack should get deeper, not just wider: same ore, much more work,
# much more money. Without this, everything after refining was just another
# ore that went the same way as the last one.
etch           24-38       60   once 1   needs refine
fuse           28-44       80   once 1   needs etch


# ---- contracts ----------------------------------------------------------
#
# VERY late on purpose, and this is the reasoning:
#
# Up to here the round target is the only structure the game has, and it is
# something you FEND OFF - it takes your money away every round. A contract is
# the first thing you actually WANT. That only works once the basics are so
# familiar that the repetition starts to feel thin. Handed out early it would
# just be a second target, and two things to fend off at once is not more
# game, it is more pressure.
#
# It also needs the tools to be interesting: by step 30 you have care, the
# market, several furnaces and the deep processing states, and the catalogue
# in data/quests.json can offer the good contracts instead of only "mine N
# blocks".
#
# It hangs off selling because a contract pays money, and money means nothing
# until you can turn ore into it.
# Schritt 30 war NICHT "spaet", sondern unerreichbar. Jeder Schritt nach aussen
# kostet das 1.8-fache: bei Schritt 30 ist ein Punkt beim Preisdeckel von einer
# Milliarde angekommen, und so viel Geld hat man erst um Runde 50 herum. Dazu
# waechst der Baum vor allem in die BREITE - wer guenstig kauft, steht nach 150
# Kaeufen erst bei Schritt 18.
#
# 14-22 ist dagegen wirklich spaet und trotzdem erreichbar: das ist dieselbe
# Gegend wie Legieren und Veredeln, also genau der Moment, in dem Abbauen und
# Verarbeiten sitzen und die Wiederholung duenn wird. In Geld sind das rund
# 190k bei Schritt 14 und 20M bei Schritt 22.
quests         14-22       90   once 3   needs sell

# Processing is a chain: washing is the start, everything else hangs off it
# through "needs". And washing itself needs "bag" - that is item.has(...).
# Because only once your program can look into the bag can it decide WHAT to
# process. So you never get offered a step whose predecessor you are missing.
#
# Alloying needs smelting: the ingredients have to be molten before you can
# pour them together (see "von" in data/legierungen.json).
alloy          18-28       34   once 1   needs smelt


# ---- more of it --------------------------------------------------------
#
# These points only show up once the matching thing has been bought.

loop+          4-          16   often 1    rise 1.20   needs while
condition+     6-          16   often 1    rise 1.20   needs if
variable+      8-          12   often 1    rise 1.20   needs variables
function+      14-         16   often 1    rise 1.22   needs functions
class+         16-         18   often 1    rise 1.22   needs classes

# One more console is one more PROGRAM running at the same time - it does not
# add to your speed, it multiplies it. Nothing else in the tree does that, so
# it starts late, costs a lot, and stays rare however far out you go.
console+       10-         45   often 1    rise 1.05


# ---- more language -----------------------------------------------------
#
# All of this used to be free: a switch is a branch, a goto is a loop, and an
# array is as many variables as you like. Anyone who knew C++ could walk past
# half the tree. Now it costs - and in exchange it can do more than what it
# replaces.
#
# Everything here hangs off the thing it improves on, so it never turns up
# before you have felt the problem it solves.

ternary        10-18       16   once 1   needs if
goto           9-17        12   once 1   needs while
container      12-20       18   once 1   needs variables
switch         14-24       26   once 2   needs if
recursion      16-26       24   once 1   needs functions


# ---- the compiler ------------------------------------------------------
#
# inline sits close behind "functions": without it a function costs more than
# it saves, and a point you regret buying is the worst kind.
#
# optimize is the only point that multiplies. Early it is worth almost
# nothing, late it is worth more than any speed point - so it may come again
# and again, but it stays rare and expensive.

inline         15-24       26   once 2   needs functions
optimize       12-         40   often 1    rise 1.18


# ---- questions to the world --------------------------------------------
#
# info is the keystone: it turns the treatment from something you look up into
# something you can ask. It sits right behind "care", because that is the
# point at which the if-chain starts to hurt.
#
# assay is its other half - without it info() stays nullptr for everything the
# game invents.

count          9-16        14   once 2   needs bag
wait           10-18       14   once 1   needs check
job            11-20       16   once 1   needs wash
status         12-20       18   once 1
market         13-22       24   once 1   needs sell

# The chart hangs off the market, not the other way round: first the number,
# then the picture. That way the page arrives at the moment you have already
# asked yourself whether now is a good time to sell.
chart          15-26       34   once 2   needs market
info           14-22       28   once 3   needs care
assay          16-26       30   once 2   needs info


# ---- more workshop ------------------------------------------------------
#
# One job at a time was the hardest ceiling in the game: the whole processing
# net collapsed into "the furnace is busy anyway". This is the point that
# multiplies throughput instead of adding to it - so it is rare and expensive.

furnace+       12-         30   often 1    rise 1.15   needs wash


# ---- values ------------------------------------------------------------
#
# The bread-and-butter stuff. High weights: most of what comes should be
# this, so that money comes in at all.

speed          2-          10   often 6
money          2-          12   often 6
regrow         2-          10   often 4
